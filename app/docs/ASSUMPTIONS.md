| ASSUMP-01 | Web UI purpose is a 5-method feature selection + consensus + validation showcase | Plan v2 defines dashboard purpose as a methodology demonstration rather than a single-model static classifier. | ASSUMP-09 | Consensus panel logic replaces the two competing notebook cells with §4.5 specification | Notebook had both a 5-method Counter and a LASSO∩Boruta union/overlap.
