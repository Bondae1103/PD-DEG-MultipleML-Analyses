# Assumptions Register

| ID | Assumption | Evidence or Reason | Impact if Wrong | Reversible? |
|---|---|---|---|---|
| ASSUMP-01 | Web UI serves an `XGBClassifier` trained on the 18 validated consensus panel genes | The 18-gene consensus panel (union of top 10 LASSO and top 10 Boruta) is the validated feature set highlighted in the presentation and notebook (`ML_final_gene_panel.csv`). An XGBoost model trained on these 18 genes reproduces the notebook's reported 86.1% LOOCV accuracy (0.8611) with AUC 0.9391 and native JSON persistence. | If the intention was the unpruned 351-gene XGBoost model, the model would require 351 features instead of 18, increasing upload friction. | Yes (retrain on 351 genes via config toggle). |
| ASSUMP-02 | Feature identifiers are HGNC Gene Symbols | UI specification §7.2 states "gene symbols matching the model". Non-technical stakeholders understand Gene Symbols (`ADAM33`, `DNAJB1`) better than Entrez integers (`80332`). A 1-to-1 bidirectional mapping dictionary is embedded. | If user uploads pure Entrez IDs, `app/core/io.py` automatically detects and maps them to symbols. | Yes. |
| ASSUMP-03 | GSE68719 analysis cohort consists of 72 samples | The original notebook Cell 0 output explicitly shows `sample.shape = (72, 2)` and `counts.shape = (39376, 73)`. `T.20` was removed as an MDS outlier (`P_cluster2`). | None; perfectly matches all notebook outputs and saved validation metrics. | Yes. |
| ASSUMP-04 | Expected expression scale is log2(CPM + 1) | The training pipeline in notebook Cell 3 applies `np.log2(cpm + 1)` where CPM is computed over library size. Tree-based models operate directly on this scale without z-score standardization. | Uploads of raw counts are flagged with a user-facing warning and normalized appropriately. | Yes. |
| ASSUMP-05 | Primary DEG table is GSE68719 limma-voom complete results | `../GSE68719/DEG_results_complete.xlsx` contains 21,537 genes from R `limma-voom` with contrast `ParkinsonsVsControl`. Filtered at `|logFC| > 1` and `adj.P.Val < 0.05`, it reproduces the exact 430 DEGs loaded in notebook Cell 0. | None; this is the verified ground truth DEG table. | Yes. |
| ASSUMP-06 | External cohorts GSE136666 and GSE168496 are provided as held-out validation sets | Sibling directories `../GSE136666` and `../GSE168496` contain raw counts, metadata, and DEG results for independent 16-sample PD cohorts. | Enhances stakeholder exploration by providing genuine external validation. | Yes. |
| ASSUMP-07 | Missing upload features are imputed with training set medians | Robustness requirement in §4.2: missing features must never cause a crash or default to zero when non-zero expression is expected. | Minimal impact if coverage is ≥ 80%. | Yes. |
